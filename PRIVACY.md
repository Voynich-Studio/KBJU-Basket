# Конфиденциальность

Корзина КБЖУ полностью работает локально.

Приложение:

- не требует регистрации;
- не собирает персональные данные;
- не показывает рекламу;
- не передаёт информацию на серверы;
- хранит данные только на устройстве пользователя.

Полная версия политики доступна на официальном сайте:

https://voynich-studio.github.io/privacy-policy.html
